### 会话的执行时机

- flush 会把记录的变化，生成 SQL 语句，但是不提交事务；

```md
操作1，新增产品
操作2，新增分类

操作3，新增关系（必须使用产品和分类的id）

不想提交事务，但是又要操作1和操作2的id，那就可以使用 flush，得到id，但是没有提交事务。
```

- commit 会先 flush，然后提交事务
