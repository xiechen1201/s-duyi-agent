# 03/note/SQLAlchemy.md

数据库驱动程序？

- asyncpg

程序操作数据库本质上就是需要一个驱动要和数据库建立连接，然后把 sql 语句发送过去执行。

数据库引擎？

引擎对象 ==> 连接对象

连接管理问题。

和数据库建立/销毁连接都是一个耗时的操作。每一个 sql 都去建立连接，性能就会吃不消，因此连接需要被管理。

如何被管理？

连接池。（把连接都放在池子里，先不销毁连接，内部维护大小，也就是最多保留多少个连接）。连接池也会占用资源，因此也不是越大越好。

"postgresql+asyncpg://admin:000000@localhost:5432/demo_db"

表示告诉 sqlalchemy，数据库的类型、要使用的数据库驱动 + 数据库其他信息，形成一个 SQL URL。

得到一个引擎对象，一个引擎对象都对应一个连接池。
