apps/web-service/test/integration/test_categories.py

```python

class TestCreateCategory:
    # 测试创建所有必填字段
    async def test_create_with_required_fields(self, async_client: AsyncClient):
      # 发送 POST 请求
        response = await async_client.post(CATEGORIES_URL, json={"name": "电子"})
        # 断言响应状态码为 201
        assert response.status_code == 201
        body = response.json()
        # 断言响应体包含 code 字段
        assert body["code"] == "0"
        data = body["data"]
        # 断言响应体包含 data 字段
        assert data["name"] == "电子"
        # 断言响应体 data 字段包含 name 字段
        assert data["description"] == ""

    async def test_create_with_all_fields(self, async_client: AsyncClient):
        response = await async_client.post(CATEGORIES_URL, json={
            "name": "食品",
            "description": "食品饮料分类",
        })
        assert response.status_code == 201
        data = response.json()["data"]
        assert data["name"] == "食品"
        assert data["description"] == "食品饮料分类"

    async def test_create_missing_name(self, async_client: AsyncClient):
        response = await async_client.post(CATEGORIES_URL, json={})
        assert response.status_code == 422
        assert response.json()["code"] == "422001"

```

可以把类更改为函数。

无论是类还是函数，必须 Test 开头，函数必须 test\_ 开头。

一个测试函数就是一个测试用例。


apps/web-service/test/conftest.py 文件

运行 uv test 的时候，寻找 conftest.py 文件。

目的是为了准备环境：

1、新增一个测试数据库

2、运行数据库迁移

3、启动 web 服务器

4、运行测试用例

5、后续处理（所有测试用例执行后）

  5.1 删除测试数据库

  5.2 关闭 web 服务器

启动 web 服务器 到新进程，可以有其他的做法。

    ASGI 应用
    ASGI 服务器

```python
@pytest.fixture(scope="session")
def event_loop():
    loop = asyncio.new_event_loop()
    asyncio.set_event_loop(loop)
    yield loop
    loop.close()
```

@pytest.fixture 装饰的函数，在运行的时候发现某个函数需要某个参数，那么 pytest 就活去找有没有同名的被修饰的函数，如果有，就调用这个函数，把返回值赋值给参数（自动化依赖注入）。

scope="session" 表示这个 fixture 是在会话级别运行的，多次调用，只运行一次，会进行缓存，整个会话期间只运行一次。

@pytest.fixture(autouse=True) 装饰的函数，自动调用。
