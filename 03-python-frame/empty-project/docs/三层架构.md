## 经典三层架构

- api 层

响应/请求处理。

- service 层

业务逻辑处理。

- dao 层

data access object。

早期 ORM 框架没有普及，之前的做法是先手动建表，每一个表对应一个模型（类似 ORM），需要手写 sql 语句。

这一层针对每一个模型进行 CRUD 操作（原子操作）。

model 层每一个模型都对应 dao 层的一个类。

- model 层

问题：dao 层是样板代码，会存在一些性能问题。
